Sugiro separar as responsabilidades desta forma:
Arquivo	Responsabilidade
github.py	Requisições HTTP e informações dos repositórios
github_installation.py	Instalação da GitHub App e tokens de instalação
repositories.py	Persistência e associação com o usuário local
choose_repo.py	Interface de seleção e onboarding
Para listar os repositórios, utilizaremos o endpoint:
GET /installation/repositories


Ele utiliza um installation access token, não o token OAuth de login, e retorna os repositórios acessíveis à instalação correspondente.

Depois, na hora de iniciar a análise, o backend deverá validar novamente se o repositório selecionado pertence à instalação autorizada.
