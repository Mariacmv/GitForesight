# 🔐 AnalisadorGit

O **AnalisadorGit** é uma ferramenta de análise de segurança integrada ao fluxo de commits do Git, desenvolvida com o objetivo de identificar possíveis dados sensíveis antes que sejam enviados para o repositório.

O sistema atua diretamente no terminal (CLI), analisando arquivos adicionados ao commit, validando mensagens de commit e classificando riscos de segurança.

---

# 📌 Objetivo do Projeto

O projeto tem como finalidade auxiliar desenvolvedores na prevenção de vazamentos de informações sensíveis durante o processo de versionamento de código.

A ferramenta realiza verificações automáticas durante os commits, permitindo identificar:

- Chaves de API;
- Tokens;
- Credenciais;
- Informações sensíveis;
- Mensagens de commit inadequadas;
- Possíveis riscos de segurança.

---

# 🚀 Funcionalidades

## ✅ Funcionalidades Implementadas

- Validação automática de commits;
- Identificação de dados sensíveis;
- Classificação de risco;
- Bloqueio de commits críticos;
- Alertas para riscos moderados;
- Validação de mensagens de commit;
- Exibição de sugestões de correção;
- Feedback em tempo real via terminal CLI.
